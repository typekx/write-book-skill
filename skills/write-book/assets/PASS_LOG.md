# Pass log

File: `pass/<id>/log.md`. Keep it after each batch of changes; at the end collect it into one change log for the author. Write entries so they make sense without knowing the tools.

```text
[cat] <chapter> | WAS: "…" | IS: "…" | reason
```

Categories: **L** logic, facts, chronology · **R** real-world detail (law, finance, place, technology) · **J** language · **S** style · **N** narration, point of view, seam · **K** collision with other volumes. Quote the relevant fragment, not the whole paragraph. Several places changed for one reason can be one entry.
