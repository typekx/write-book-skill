# Unit report

In light mode the three-point report from `references/light-mode.md` is enough. The full version follows.

Unit, version, date of work, prose file and scope of the task:

Status: awaiting acceptance / accepted / accepted with notes / to be rewritten.

Words (project counter): now … ; target from the card … ; previous version … (for a correction).

## 1. Scenes

Point of view, date with weekday and place, times, the change in the scene; length and how it was counted; limits of summary scenes.

## 2. Canon

Facts used and pointers to source scenes (volume, chapter). What was checked by searching before writing. Discrepancies between the card and the canon and how they were resolved.

## 3. New facts

Facts actually added to the prose. Separate them from characters' hypotheses and future plans. New proper names and the status of their collision test.

## 4. Departures from the plan

What changed, why and with what effect on the following units. Confirmation that the card was corrected.

## 5. Dependence on the author's decisions

Decisions used and unresolved variants affecting further work. The fallback variant for beats that depend on a proposal not yet accepted.

## 6. Knowledge and state

Growth of each character's knowledge, how it was passed on, objects, injuries, relationships, forms of address, series counters.

## 7. Seeds and payoffs

What was introduced, developed or closed. Pointer to the earlier seed.

Dependencies on future volumes: which conditions for payoffs were fulfilled, what is still only a plan and whether the series architecture needs updating.

## 8. Questions and open matters

Things that need a decision, a source check or further control. If none, write "none".

## 9. Self-check and result

Scope of actual reading; checks done and not done; technical check result (project counters, typography, dates, work leftovers, comparison with the previous version); false alarms left with justification; errors corrected; remaining limitations; state update and the next step. A tool's result does not replace judging the prose.

Name the style profile used for comparison, any drift, places that disturb immersion and decisions about repeated thoughts, patterns and replacement tics. Say what was deliberately kept. After editing, confirm the reread and the check for lost information; no "AI percentage".
