# Manuscript

Create volume folders only within the ordered project. Each unit has its own prose file. Save reports in control.

Example volume layout, to use once the structure is agreed:

```text
Volume_1/
  ORDER.md
  00_prologue.md
  01_chapter_1.md
  02_chapter_2.md
```

Do not create empty chapters as proof of progress. In `ORDER.md` list every existing unit separately and in its real order, including interludes between chapters. Mark planned items as planned; do not export them as written prose.

List model:

| Order | Unit ID | Chosen file | Type | Story date | POV | Words | Status | Include in export |
|---|---|---|---|---|---|---|---|---|

Statuses: plan, awaiting acceptance, accepted, accepted with notes, to be rewritten, withdrawn. The writing order may differ from the reading order (e.g. a prologue written after the chapter that fixes its details); record such an exception.

Before assembling, check that every chosen file exists, that there are no duplicates and that the statuses match. After assembling, compare the word count of the whole with the sum of the units. Archived variants of a unit do not enter the whole next to its current version.
