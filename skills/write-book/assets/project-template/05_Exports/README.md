# Exports

Save ordered output files here, e.g. assembled Markdown, DOCX, PDF or EPUB. This template performs no conversion. A readable README keeps the folder in the repository without an empty `.gitkeep`.

| Output file | Format | Sources and order list | Source version / commit | Export date | Tool and parameters | Content check | Appearance check |
|---|---|---|---|---|---|---|---|

A change in a source means the previous export may be out of date. The appearance check covers, among other things, headings, dialogue, special characters and the table of contents. Do not mark it as done just because the conversion finished without errors.

Optional GitHub Actions can be set up as a separate task once the assembly method, tools, fonts and formats are agreed. Generating a file is not consent to share it publicly.
