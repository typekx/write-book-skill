# State, reports and decisions

- [Style, immersion and formulaic prose audit](STYLE_AND_IMMERSION_AUDIT.md).
- [Validation and change impact across volumes](VALIDATION_AND_CHANGE_IMPACT.md).

Record the current state, the author's decisions, unit reports and module audits here. With the skill, use its `CONTINUATION_STATE.md` and `UNIT_REPORT.md` templates; copy them into the project when needed.

Open the state with a current summary. Older entries have a separate history section. When a volume is closed, mark it as finished and do not leave an old instruction such as "write the prologue" as the current step.

## Decision register

| ID | Date and the author's instruction | Question and options | Recommendation | Ruling | Scope of change | Units and registers affected | Status |
|---|---|---|---|---|---|---|---|

Statuses: open, recommendation, decided, implemented in the text. One register per project; mark parallel versions of rulings as archived and name the valid one.
