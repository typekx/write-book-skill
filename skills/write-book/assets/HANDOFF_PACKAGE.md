State as of [date]. Written: [range, word count]. To be written: [range, target words]. The model's first task: [review without prose / cards / unit].

## 1. Setup (for the author)

1. Create a workspace [name] and choose the model [model]. If possible, switch off web search while writing prose.
2. Paste the whole of section 3 of this file into the workspace instructions.
3. Add the files in order of importance (with a file limit, add the first ones):
   1. this file;
   2. the state after the last range;
   3. the plan and cards for the next range;
   4. registers and open decisions;
   5. the full text of the current volume;
   6. the style guide and content rules;
   7. earlier volumes (canon);
   8. the series bible and the plan of later volumes.
4. Write one unit per message. Save each result locally as [file name pattern]; the model's environment may lose files.
5. After each unit run the check [command] or ask the model for the self-check in section 5.

## 3. Standing instructions (paste into the workspace instructions)

You are [role] writing the [genre] "[title]", [volume], by [author]. You write in [language], in the style of the units already written. The volume has about [N] words.

**The author's absolute rules:** [e.g. clean text without comments, hidden characters, notes or square brackets; the report separately].

**Source hierarchy (higher wins):** 1. [canon of volume I, version]; 2. [...]; 3. the written text of the current volume; 4. [registers, style guide]; 5. plan and cards; 6. your own idea only as a small new fact recorded in the report. If a card contradicts the canon, write according to the canon and describe it in the report. Check every fact about the past by searching the files before writing it.

**Point of view:** [who can be POV]; never a point of view: [list]. One point of view per scene. The narrator does not foreshadow.

**Forms of address:** [pairs of characters and forms].

**Style (limits per unit):** [bans and limits].

**Typography:** [dialogue, quotation marks, numbers, italics, foreign words, uninflected names, names still forbidden].

**Headings and date line:** [format; the weekday must match the calendar].

**Length:** [minimums and targets]. Plan at about 110% of the target from the start; make up missing words with beats from the card, not description.

**Content boundaries:** [rules, forbidden juxtapositions].

**Hook:** the last sentence carries the meaning of the card's hook. **Open decisions:** stop before the dependent scene and give 2–3 options with consequences.

**After each unit you deliver:** A) clean text; B) a 9-point report.

## 4. Unit report

1. Scene plan with times. 2. Canon: what I used and what I checked. 3. New facts. 4. Departures from the card and why. 5. Beats depending on the author's decisions and the fallback variant. 6. Knowledge after the unit. 7. Seeds. 8. Questions for the author. 9. Self-check: words, counters, typography.

## 5. Ready prompts

**Review (no prose):** "Read [files]. Also read [latest units] to catch the voice. Do not write prose. List: (a) contradictions between the plan and the canon, with proposals; (b) canon facts checked before the first unit, with the result and a reference; (c) questions for the author."

**Cards (if missing):** "Write unit cards for [range] in the format of [model]. Do not write prose."

**Unit:** "Write [unit] according to the card and the standing instructions. First check in the canon every fact about the past you will use. Write at about 110% of the card's length. Deliver A) clean text and B) a 9-point report."

**Self-check without a script:** "Check [unit]: count words, tics, antitheses and colons in narration; list [disallowed characters]; list sentences contradicting the canon or the knowledge table; give corrections as 'was → should be' pairs, without rewriting the whole."

**End of module:** "Write the module report: table of lengths (plan, text, difference), canon agreements, unit reports, checklist, questions. Check continuity of [recurring props], forms of address and dates."

**Short commands** (add to the standing instructions if the author wants to write briefly): `review`/`przegląd` = the review prompt; `cards`/`karty` = cards; `write N`/`pisz N` = unit N; `check N`/`sprawdź N` = self-check; `module`/`moduł` = end of module. The command is the first word of the message.
